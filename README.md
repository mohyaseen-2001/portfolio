# My Personal Portfolio

A responsive personal portfolio website created using HTML and CSS.

## About the Project

This project presents my skills, projects, and contact information in a clean and modern portfolio website.

## Features

- Responsive design for mobile and desktop screens
- Animated gradient background
- Sticky Bootstrap navbar and footer
- Skills section with hover effects
- Projects gallery with project previews
- Contact links and contact form
- CSS transitions and animations

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5 (Navbar and Footer only)

## How to Run the Project

1. Download or clone the project files.
2. Open `index.html` in any web browser.
